# MissionSchema

**Producer:** P3 (Scenario Service)  
**Consumers:** P1, P4, P5

## Definition

```json
{
  "mission_id": "uuid (string)",
  "title": "string",
  "description": "string",
  "difficulty": "BEGINNER | INTERMEDIATE | ADVANCED",
  "estimated_time_minutes": "integer",
  "objectives": ["string"],
  "resources_required": {
    "gcp_services": ["string"],
    "permissions": ["string"]
  },
  "initial_state": "object",
  "expected_outcome": "object",
  "success_criteria": ["string"],
  "created_at": "ISO 8601 timestamp (string)"
}
```

## Field Details

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `mission_id` | UUID | Yes | Unique mission identifier |
| `title` | String | Yes | Mission title |
| `description` | String | Yes | Mission description |
| `difficulty` | String | Yes | Difficulty level: BEGINNER, INTERMEDIATE, or ADVANCED |
| `estimated_time_minutes` | Integer | Yes | Estimated completion time in minutes |
| `objectives` | Array of strings | Yes | List of learning objectives |
| `resources_required` | Object | Yes | GCP resources and permissions needed |
| `initial_state` | Object | Yes | Initial state of the GCP environment |
| `expected_outcome` | Object | Yes | Expected state after mission completion |
| `success_criteria` | Array of strings | Yes | List of success criteria to evaluate |
| `created_at` | Timestamp | Yes | Mission creation timestamp |

## Rules

- `mission_id` is guaranteed to be unique and non-null
- `difficulty` must be one of the defined enum values
- `resources_required` is a required object with at minimum `gcp_services` and `permissions` arrays
- Missions are generated by P3 and read-only for consumers

## Usage

Produced by:
- `POST /scenarios/generate` — Returns MissionSchema(s)

Consumed by:
- `P4` — To create GCP environments matching the mission
- `P5` — To evaluate challenge completion against expected outcomes
- `P1` — To display mission information to learner
