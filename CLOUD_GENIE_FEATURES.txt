  ☁️  CLOUD GENIE: Engaging Provisioning Experience  ☁️

WHAT IT IS:
  An interactive learning experience displayed during the 45-90 second
  GCP environment provisioning. Instead of a boring spinner, users learn
  cloud concepts, answer quizzes, and watch progress advance.

  FEATURES
═══════════════════════════════════════════════════════════════════════════════

✅ FLOATING CLOUD
   • Smooth up/down/left/right animation
   • CSS-based (GPU accelerated)
   • Always visible at top

✅ AUTO-ADVANCING TIMELINE
   • Steps complete every 800-2000ms
   • Current step pulses with spinner
   • Completed steps turn green
   • If backend finishes early, all remaining steps complete instantly

✅ ROTATING LEARNING CARDS
   • Switches every 5 seconds
   • Randomly chosen each session
   • Never shows same sequence twice
   • 5 categories: Facts, Tips, Interview, Behind-the-Scenes, Hints

✅ INTERACTIVE QUIZ
   • 5 questions, rotates every 6 seconds
   • Click to answer (once only)
   • Shows answer + explanation
   • Auto-advances to next question

✅ ENCOURAGING FOOTER
   • Changes every 4 seconds
   • 10 different positive messages
   • Reminds user "almost there"

✅ ERROR STATE
   • Red icon + "Launch Failed"
   • Displays error message
   • User can try again

✅ SUCCESS STATE
   • Green checkmark
   • "Cloud environment ready!"
   • Brief pause (500-800ms)
   • Auto-navigates to mission
